    Decide whether SessionStart installs dependencies itself
    Convenience versus running npm in a hook
    decide
    Today a fresh install reports "dependencies missing" and does nothing until the user runs hush-setup. Auto-running npm install in the SessionStart hook fixes that but adds network access and a minute of wait to a hook with a 30 s timeout.
    DecideOption A: keep manual, but make the SessionStart message impossible to miss. Option B: spawn npm install detached, same as the daemon, and report "installing" until it finishes. B is about ten lines.
